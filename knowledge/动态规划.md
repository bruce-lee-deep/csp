## 区间动态规划

戳气球这道题最关键的是从最后一个被戳破的气球去思考问题。

因为你正着去思考问题的话，每戳破一个气球原始的数据就会改变，处理会变得困难起来，但是如果考虑最后一个，那区间内的就肯定是已经被戳破的。

**状态转移方程**

$$
dp[i][j] = \max_{i < k < j} \left( dp[i][k] + dp[k][j] + a[i] \cdot a[k] \cdot a[j] \right)
$$

**核心代码**

```C++
for(int len=2;len<=n+1;len++){
  	//len是区间的长度，从小区间去遍历大区间，大区间要用到小区间的结果
	for(int i=0;i<+len<=n+1;i++){
      	j=i+len;
      	for(int k=i+1;k<j;k++){
          	dp[i][j]=max(
              	dp[i][j],
              	dp[i][k]+dp[k][j]+a[i]*a[k]*a[j]
            );
        }
    }
}
```

## 0-1背包

有n件物品，每件只能选一次，第i件的重量为weight[i],价值是value[i]，背包容量是bag，问能装下的最大总价值是多少？

有以下变式：

1.是否能刚好装满背包

2.双重背包

模板

```C++
vector<int> dp(bag+1,0);
//遍历每件物品
for(int i=0;i<n;i++){
  for(int j=bag;j>=weight[i];j--){
    dp[j]=max(dp[j],dp[j-weight[i]]+value[i]);
  }
}
cout<<dp[bag]<<endl;
```
